הקדמה לתוכנת BIM המובילה בעולם

Autodesk Revit היא תוכנת BIM (Building Information Modeling) מובילה המשמשת אדריכלים, מהנדסים ואנשי בינוי ברחבי העולם. Revit עובדת עם מודלים תלת-ממדיים חכמים — כל רכיב (קיר, חלון, קורה) הוא אובייקט עם מידע, לא רק קווים.

🧱 קירות (Walls) — יסודות המבנה ▼

קירות ב-Revit אינם רק קווים, אלא מערכות רב-שכבתיות המכילות מידע תרמי, אקוסטי ומבני.

1
בחירת כלי הקיר (WA)
Architecture → Wall. שים לב לבחירה בין Architectural (אדריכלי) ל-Structural (קונסטרוקטיבי).
2
הגדרת אילוצים (Constraints)
קבע את ה-Base Constraint (רצפת בסיס) ואת ה-Top Constraint (עד איזה מפלס הקיר מגיע).
3
קביעת קו המיקום (Location Line)
בחר אם לשרטט לפי מרכז הקיר, פנים חוץ או פנים פנים. קריטי לשינויי עובי עתידיים.

אופציות מידול שיטתיות:

Basic Wall קיר סטנדרטי המורכב משכבות חומר. ניתן לערוך את ה-Structure ולהוסיף בידוד, טיח וחיפוי.
Curtain Wall חזית זכוכית עם Grids, Mullions ו-Panels. עריכה ב-Edit Type.
Stacked Wall חיבור אנכי של מספר קירות בסוגים שונים (למשל: בסיס בטון ומעליו קיר בלוקים).
In-Place Wall קיר מותאם ייחודי לפרויקט. Massing → Wall from Face.
🧭 מה חשוב לבדוק כשממדלים קירות

Constraints: עגן קירות ל-Level נכון כדי למנוע קפיצות גובה בהמשך. Location Line: קבע מראש אם עובדים לפי מרכז קיר או לפי פני גמר — זה משפיע על כל שינוי עובי עתידי. Wall Joins: בדוק חיבורי פינות עם Modify → Wall Joins כדי למנוע פינות מלוכלכות. Edit Type → Structure: הגדר שכבות ליבה, גמר ובידוד לצורך חתכים, כמויות ותיאום.

🏠 גגות (Roofs) — סגירת המעטפת ▼

יצירת גגות דורשת הבנה של שיפועים וניקוזים. Revit מאפשרת מידול גגות בשלוש שיטות עיקריות:

Roof by Footprint שרטוט קווי המתאר של הגג בתוכנית. הגדרת שיפוע (Slope) לכל צלע בנפרד ליצירת גג רעפים או גג שטוח.
Roof by Extrusion יצירת גג על ידי שרטוט הפרופיל שלו בחתך או בחזית ומתיחתו לאורך המבנה. מתאים לגגות קמרוניים או צורניים.
Roof by Face הלבשת גג על פאה של מסה (Mass) מורכבת. השיטה המתקדמת ביותר לאדריכלות אמורפית.
🌧️ טיפים לגגות ושיפועים

ב-Footprint Roof אפשר להפעיל Defines Slope רק על קווים מסוימים כדי לקבל שיפוע נכון. לגג שטוח עם ניקוז עדיף לעבוד עם Slope Arrow או שיפוע קטן ברצפה/גג. אחרי יצירת הגג בדוק Attach Top/Base לקירות, וודא חיתוך נקי בחתכים ובחזיתות.

⬜ רצפות (Floors) — מפלסי עבודה ▼

רצפות הן אלמנטים אופקיים המגדירים את שטחי הפנים והחוץ של הפרויקט.

Floor Architectural רצפה הכוללת שכבות גמר (ריצוף, מילוי). משמשת לחישובי כמויות של חומרי גמר.
Floor Structural רצפה קונסטרוקטיבית (בטון מזוין, פלדה). כוללת פרמטרים לחישוב עומסים.
Slab Edge הוספת עיבוי קצה או חגורת בטון לקצה הרצפה לפי פרופיל נבחר.
📏 מה רצוי לזכור ברצפות

רצפה חייבת סקיצה סגורה לחלוטין. אם יש פיר, פתח מדרגות או חור שירות — צייר לולאה פנימית בסקיצה או השתמש ב-Opening. ברצפות חוץ, מרפסות ואזורים רטובים כדאי לבדוק Slope Arrow, Offset מהמפלס, וחומרי גמר ב-Edit Type לצורך תיעוד וכמויות.

🪜 מדרגות (Stairs) — תנועה אנכית ▼

כלי המדרגות ב-Revit הוא אחד המורכבים והחזקים ביותר, המבוסס על חוקי תכנון (Rise/Run).

Stair by Component הרכבת מדרגות מחלקים מוכנים: מהלכים (Runs), פודסטים (Landings) ותמיכות (Supports).
Stair by Sketch שרטוט ידני של גבולות המדרגה (Boundary) והשלחים (Risers). מאפשר יצירת מדרגות פיסוליות.
Multistory Stair חיבור מדרגות לאורך מספר קומות בלחיצת כפתור אחת, עם עדכון אוטומטי של כל המהלכים.
🪜 בקרת איכות למדרגות

בדוק תמיד את Base Level, Top Level, מספר ה-Risers שנותרו, רוחב מהלך, Landing ומעקות. אם Revit לא מצליח לפתור את המדרגות, עבור ל-Sketch כדי לשלוט ידנית בגבולות וב-Risers. בפרויקטים רבי-קומות עדיף להשתמש ב-Multistory Stair כדי למנוע כפילויות שגויות.

🚪 פתחים (Doors & Windows) ▼

אלמנטים אלו הם "טפילים" (Hosted) — הם חייבים קיר כדי להתקיים.

Standard Placement הצבת דלת/חלון מתוך ספריית המשפחות. חיתוך הקיר מתבצע אוטומטית.
Sill & Head Height שליטה מדויקת בגובה הסף וגובה הראש של הפתח דרך לוח המאפיינים.
Tagging סימון אוטומטי של הפתחים לצורך יצירת רשימות נגרות ואלומיניום (Schedules).
🚪 דלתות וחלונות — בדיקות חשובות

מכיוון שמדובר ב-Hosted Families, ודא שהקיר המארח נכון ושכיוון הפתיחה/השיקוף תקין. נהל Sill Height, Head Height, Mark, Comments ו-Fire Rating כבר מההתחלה כדי להפיק רשימות פתחים מסודרות. אם רוצים תיעוד מדויק, שלב Tag on Placement ו-Schedule לפי Family ו-Type.

⬆️ תקרות (Ceilings) — חללי פנים וגמרים ▼

תקרות ב-Revit אינן רק קו גרפי ב-RCP אלא אלמנט עם גובה, שכבות, חומר וגאומטריה משלו. הן חשובות לתיאום עם תאורה, מיזוג, ספרינקלרים ופתחים.

Automatic Ceiling לחיצה בתוך חדר סגור יוצרת תקרה אוטומטית לפי גבולות החלל. מהיר מאוד לפרויקטים טיפוסיים.
Sketch Ceiling תקרה בשרטוט ידני לגבולות מורכבים, נישות, מסדרונות, חללים כפולים ומעברי מערכות.
Reflected Ceiling Plan תצוגת RCP מיועדת לתיעוד תאורה, ספרינקלרים, גרידים אקוסטיים ופתחים בתקרה.
💡 טיפ תכנוני

הגדר Height Offset from Level בזהירות, ושמור עקביות בין סוגי תקרות, גופי תאורה ופתחים. כאשר יש תקרה אקוסטית עם גריד, כדאי לתאם את מיקום הפנלים והגופים מול ה-RCP ולא רק בתוכנית אדריכלית רגילה.

🏠 חדרים, שטחים ורכיבים (Rooms, Areas & Components) ▼

כאן Revit הופך ממודל גיאומטרי למודל מידע: חדרים, שטחים ורכיבים מאפשרים להפיק נתונים אמינים לתיעוד, תמחור, פרוגרמה ותיאום.

Rooms מחשבים שטח, היקף ונפח, ומחזיקים נתונים כמו Name, Number, Department ו-Finish.
Areas מתאימים לחישובי שטחים ברמת רישוי, ברוטו/נטו, חישובי השכרה ועמידה בתוכנית שטחים.
Components ריהוט, ציוד ואלמנטים משלימים שמוסיפים מידע, כמויות וקואורדינציה לחללי הפנים.

כדאי להגדיר Room Tags, Color Schemes ו-Schedules כבר בשלבי המודל הראשונים. כך אפשר לזהות חדרים לא סגורים, שטחים חסרים, רכיבים לא מתויגים וחריגות פרוגרמה לפני שלב ההגשה.

📋 מה זה בכלל? קיר (Wall) ב-Revit הוא אובייקט חכם בעל עובי, גובה, חומרים ושכבות — ולא סתם קו כמו ב-AutoCAD. הקיר מחבר פינות אוטומטית, מאפשר הצבת דלתות/חלונות ישירות בתוכו, ומציג את כל השכבות (בטון, בידוד, טיח) בחתך.

📋 מה זה בכלל? כלי רב-עוצמה לשמירה על אחידות גרפית. במקום להגדיר ידנית כל מבט, יוצרים "תבנית" הכוללת קנה מידה, רמת פירוט, והגדרות נראות (VG). כשמשנים את התבנית, כל המבטים המשויכים אליה מתעדכנת מיידית.
📌 שלב-אחר-שלב: ① View → View Templates → Manage View Templates. ② צרו תבנית חדשה (למשל "תוכנית עבודה חשמל"). ③ הגדירו את כל הפרמטרים הרצויים. ④ ב-Properties של המבט, תחת Identity Data, בחרו את ה-View Template שיצרתם.
💡 טיפ: אם אתם רוצים לשנות משהו זמנית במבט שנעול ע"י תבנית, ניתן להשתמש ב-Enable Temporary View Properties בתחתית המסך.–View → Graphics
VFFilters — מסננים
📋 מה זה בכלל? דרך חכמה לצבוע או להסתיר אלמנטים לפי חוקים. למשל: "צבע את כל צינורות המים הקרים בכחול" או "הסתר את כל הקירות שגובהם פחות מ-100 ס"מ".
📌 שלב-אחר-שלב: ① הקלידו VG ועברו ללשונית Filters. ② לחץ על Edit/New ליצירת פילטר חדש. ③ הגדר חוק (למשל: Category: Pipes, Rule: System Name contains "Cold Water"). ④ הוסף את הפילטר למבט והגדר לו Override (צבע כחול).
💡 טיפ: פילטרים הם הדרך הטובה ביותר ליצור תוכניות מערכות ברורות וקריאות.–VG → Filters
VOView Overrides — שינויי מראה בתצוגה
📋 מה זה בכלל? שינוי המראה של אלמנט ספציפי במבט מסוים בלבד, מבלי להשפיע על שאר הפרויקט. זהו "תיקון מקומי" לצרכים גרפיים מיוחדים.
📌 שלב-אחר-שלב: ① בחרו את האלמנט בשרטוט. ② קליק ימני → Override Graphics in View → By Element. ③ שנו את הצבע, השקיפות או סגנון הקו. ④ לחצו OK.
💡 טיפ: השתמשו בזה במשורה. אם אתם צריכים לשנות הרבה אלמנטים, עדיף להשתמש ב-Filters או ב-Visibility/Graphics (VG).–קליק ימני → Override
SBScope Box — תיבת היקף תצוגה
📋 מה זה בכלל? תיבה תלת-מימדית המגדירה אזור ספציפי בפרויקט. היא משמשת לחיתוך אחיד של מבטים (Crop Region) ולקביעת גובה אחיד של מפלסים וגרידים באותו אזור.
📌 שלב-אחר-שלב: ① View → Scope Box. ② שרטטו מלבן סביב האזור הרצוי (למשל "אגף א'"). ③ תנו שם לתיבה ב-Properties. ④ במבטים הרלוונטיים, הגדירו ב-Properties תחת Scope Box את השם שיצרתם.
💡 טיפ: מעולה לפרויקטים גדולים המחולקים לאגפים — זה מבטיח שכל התוכניות של אותו אגף יהיו חתוכות בדיוק באותו מקום.–View → Create
CACallout — מפת הגדלה
📋 מה זה בכלל? יצירת מבט מוגדל של אזור ספציפי מתוך תוכנית קיימת (למשל: הגדלת חדר מדרגות או פיר חשמל). ה-Callout מקושר למבט הראשי ומתעדכן איתו.
📌 שלב-אחר-שלב: ① View → Callout. ② שרטטו מלבן סביב האזור להגדלה. ③ נוצר מבט חדש ב-Project Browser. ④ פתחו את המבט החדש ושנו את קנה המידה (למשל ל-1:25) להוספת פרטים מדויקים.
💡 טיפ: ניתן לשנות את צורת בועת ה-Callout בתוכנית הראשית ע"י גרירת הנקודות הכחולות.–View → Create
CVCamera — מצלמת Perspective
📋 מה זה בכלל? יצירת מבט תלת-מימדי מנקודת מבט של אדם העומד בחלל. זהו הכלי הבסיסי ליצירת הדמיות ופרספקטיבות של הפרויקט.
📌 שלב-אחר-שלב: ① View → 3D View → Camera. ② לחצו בתוכנית בנקודה שבה אתם "עומדים". ③ גררו את העכבר לכיוון שאליו אתם "מסתכלים" ולחצו שוב. ④ המבט ייפתח אוטומטית.
💡 טיפ: ניתן לשנות את גובה העיניים (Eye Elevation) ב-Properties כדי ליצור מבט ממעוף הציפור או מגובה נמוך.–View → Create
SWSection — חתך
📋 מה זה בכלל? יצירת מבט אנכי דרך המבנה. החתך ב-Revit הוא "חי" — כל שינוי שתעשו בחתך יתעדכן בתוכנית וב-3D, ולהיפך.
📌 שלב-אחר-שלב: ① View → Section (או מהסרגל העליון). ② לחצו בנקודת ההתחלה וגררו לנקודת הסיום. ③ לחצו פעמיים על ה"ראש" הכחול של החתך כדי לפתוח אותו. ④ כוונו את עומק החתך ע"י גרירת הקו המקווקו בתוכנית.
💡 טיפ: ניתן "לשבור" את קו החתך (Split Segment) כדי לעבור דרך אזורים שונים במבנה בקו אחד.–View → Create
EVElevation — חזית
📋 מה זה בכלל? יצירת מבט חזית (צד) של המבנה או חזית פנים של חדר. הכלי מזהה אוטומטית קירות ומפנה את המבט אליהם.
📌 שלב-אחר-שלב: ① View → Elevation. ② קרבו את הסמן לקיר בתוכנית - הסמל יסתובב אוטומטית לכיוון הקיר. ③ לחצו להצבה. ④ לחצו פעמיים על ראש החץ כדי לפתוח את המבט.
💡 טיפ: ניתן להוסיף "ראשי חץ" נוספים לאותו סמל כדי ליצור 4 חזיתות פנים של חדר בלחיצה אחת.–View → Create
3DDefault 3D View — תצוגת תלת-מימד
📋 מה זה בכלל? המבט המרכזי לבחינת המודל ב-3D. כאן ניתן לראות איך כל המערכות משתלבות יחד בחלל.
📌 שלב-אחר-שלב: ① לחצו על אייקון הבית הקטן בסרגל העליון (או View → 3D View). ② השתמשו ב-Shift + לחיצה על הגלגלת בעכבר כדי לסובב את המודל (Orbit). ③ השתמשו ב-Section Box ב-Properties כדי "לחתוך" את המודל ולראות מה קורה בפנים.
💡 טיפ: אם הלכתם לאיבוד במרחב, לחצו קליק ימני על ה-ViewCube (הקוביה בצד) ובחרו "Orient to View" כדי לראות את ה-3D בדיוק לפי חתך או תוכנית ספציפיים.–View → Create
WKWalkthrough — סיור וירטואלי
📋 מה זה בכלל? יצירת סרטון אנימציה שעובר בתוך המודל לאורך מסלול שהגדרתם. זה מאפשר ללקוח "לטייל" בבניין עוד לפני שהוא נבנה.
📌 שלב-אחר-שלב: ① View → 3D View → Walkthrough. ② לחצו על נקודות בתוכנית כדי להגדיר את מסלול ההליכה. ③ לחצו Finish. ④ עברו למבט ה-Walkthrough שנוצר והשתמשו ב-Edit Walkthrough כדי להפעיל את האנימציה.
💡 טיפ: ניתן לייצא את הסרטון לקובץ AVI דרך File → Export → Images and Animations.–View → Create
DVDuplicate View — שכפול תצוגה
📋 מה זה בכלל? יצירת עותק נוסף של מבט קיים. יש שלוש דרכים לעשות זאת, תלוי אם רוצים להעתיק גם את המידות והטקסטים או רק את המודל.
📌 שלב-אחר-שלב: ① קליק ימני על המבט ב-Project Browser. ② בחרו Duplicate View. ③ בחרו: Duplicate (רק המודל), With Detailing (מודל + מידות וטקסט), או As Dependent (עותק מקושר).
💡 טיפ: השתמשו ב-As Dependent כשאתם צריכים לחלק תוכנית גדולה למספר גיליונות קטנים.–קליק ימני ב-Browser
RDRendering — רנדר
📋 מה זה בכלל? תהליך הפיכת המודל התלת-מימדי לתמונה ריאליסטית עם תאורה, צללים וחומרים אמיתיים.
📌 שלב-אחר-שלב: ① פתחו מבט 3D או Camera. ② הקלידו RR לפתיחת חלון ה-Rendering. ③ הגדירו איכות (Draft לניסיון, High לתוצאה סופית) ותאורה (Sun/Artificial). ④ לחצו Render.
💡 טיפ: רנדור במחשב המקומי לוקח זמן ומשאבים. ב-2026 מומלץ להשתמש ב-Render in Cloud כדי להמשיך לעבוד בזמן שהענן של Autodesk מרנדר עבורכם.RRView → Presentation

LRLink Revit — קישור קובץ Revit
📋 מה זה בכלל? עבודה על קובץ Revit חיצוני בתוך הפרויקט שלך מבלי להעתיק אותו. זהו הבסיס לעבודה שיתופית: האדריכל מקשר את קובץ הקונסטרוקציה, ומהנדס החשמל מקשר את קובץ האדריכלות.
📌 שלב-אחר-שלב: ① Insert → Link Revit. ② בחרו את הקובץ הרצוי. ③ הגדירו Positioning (בדרך כלל Auto - Origin to Origin). ④ הקובץ יופיע במודל שלכם.
💡 טיפ: אם הקובץ המקורי מתעדכן, פשוט לחצו על Manage Links וטענו אותו מחדש (Reload) כדי לראות את השינויים.–Insert → Link
LILink IFC — קישור קובץ IFC
📋 מה זה בכלל? קישור קובץ בפורמט IFC (פורמט בינלאומי פתוח) לתוך Revit. זה מאפשר לעבוד עם יועצים שמשתמשים בתוכנות אחרות כמו ArchiCAD או Tekla.
📌 שלב-אחר-שלב: ① Insert → Link IFC. ② בחרו את קובץ ה-IFC. ③ Revit ייצור קובץ עזר (Shared Parameters) ויציג את המודל המקושר. ④ ניתן לנהל את הקישור דרך Manage Links.
💡 טיפ: ב-2026 התמיכה ב-IFC4 שופרה משמעותית, מה שמאפשר העברת מידע מדויקת יותר בין תוכנות שונות.–Insert → Link
LCLink CAD — קישור קובץ DWG/DXF
📋 מה זה בכלל? הצגת שרטוט אוטוקאד (DWG) בתוך Revit כרקע לשרטוט. בניגוד לייבוא (Import), קישור שומר על קשר עם הקובץ המקורי.
📌 שלב-אחר-שלב: ① Insert → Link CAD. ② בחרו את קובץ ה-DWG. ③ סמנו "Current view only" אם אתם רוצים לראות אותו רק בתוכנית הנוכחית. ④ הגדירו יחידות מידה (בדרך כלל Meters או Millimeters).
💡 טיפ: תמיד עדיף להשתמש ב-Link CAD ולא ב-Import CAD כדי למנוע "לכלוך" של הפרויקט בשכבות מיותרות מאוטוקאד.–Insert → Link
ICImport CAD — ייבוא קובץ אוטוקאד
📋 מה זה בכלל? הכנסת שרטוט DWG לתוך Revit בצורה קבועה. בניגוד ל-Link, כאן הקובץ הופך לחלק בלתי נפרד מהפרויקט ואינו מתעדכן אם קובץ המקור משתנה.
📌 שלב-אחר-שלב: ① Insert → Import CAD. ② בחר את הקובץ. ③ הגדר יחידות מידה (Meters/Millimeters). ④ סמן "Current View Only" אם תרצה לראות אותו רק במבט הנוכחי. ⑤ לחץ Open.
💡 אזהרה: ייבוא קבצי CAD עלול להכביד מאוד על הפרויקט ולגרום לבעיות ביצועים. מומלץ להשתמש ב-Link CAD ברוב המקרים, ולהשתמש ב-Import רק עבור פרטים קטנים שרוצים להפוך ל-Families.–Insert → Import
MLManage Links — ניהול קישורים
📋 מה זה בכלל? מרכז הבקרה של כל הקבצים החיצוניים המקושרים לפרויקט (Revit, CAD, IFC, תמונות). כאן ניתן לראות מה טעון, מה חסר ומה צריך עדכון.
📌 שלב-אחר-שלב: ① Manage → Manage Links. ② עברו בין הלשוניות (Revit / CAD Formats). ③ השתמשו ב-Reload לעדכון קובץ שהשתנה, או ב-Unload להסרה זמנית מהתצוגה כדי להאיץ את העבודה.
💡 טיפ: אם העברתם את הקבצים לתיקייה אחרת והקישור נשבר, השתמשו ב-Reload From כדי להגדיר את הנתיב החדש.–Manage → Manage
BIBind Link — הטמעת קישור
📋 מה זה בכלל? הפיכת קובץ מקושר (Link) לחלק בלתי נפרד מהקובץ הנוכחי שלכם. זה הופך את הקישור ל-Group (קבוצה) שניתן לפרק ולערוך.
📌 שלב-אחר-שלב: ① בחרו את הקובץ המקושר בשרטוט. ② בריבון (Ribbon) למעלה, לחצו על Bind Link. ③ בחרו אם לכלול מידות וחדרים. ④ לחצו OK.
💡 אזהרה: פעולה זו מגדילה מאוד את נפח הקובץ ועלולה להאט אותו. השתמשו בזה רק כשאתם בטוחים שאין יותר צורך בקישור חיצוני.–Modify → Link
EIExport IFC — ייצוא לפורמט IFC
📋 מה זה בכלל? שמירת המודל שלכם בפורמט IFC כדי שיועצים אחרים יוכלו לפתוח אותו בתוכנות שלהם. זהו הסטנדרט לעבודה בשיטת BIM.
📌 שלב-אחר-שלב: ① File → Export → IFC. ② בחרו את גרסת ה-IFC הנדרשת (בדרך כלל IFC2x3 או IFC4). ③ הגדירו את ה-Setup (מיפוי שכבות ופרמטרים). ④ לחצו Export.
💡 טיפ: וודאו שהגדרתם נכון את ה-Project Base Point לפני הייצוא כדי שהמודל ינחת במקום הנכון אצל היועצים.–File → Export
ECExport CAD — ייצוא ל-DWG/DXF
📋 מה זה בכלל? ייצוא התוכניות שלכם לפורמט DWG (אוטוקאד). שימושי לשליחת שרטוטים ליועצים או קבלנים שעדיין עובדים בדו-מימד.
📌 שלב-אחר-שלב: ① File → Export → CAD Formats → DWG. ② בחרו את המבטים או הגיליונות לייצוא. ③ הגדירו את הגדרות הייצוא (צבעים, שכבות, יחידות מידה). ④ לחצו Next ושמרו את הקבצים.
💡 טיפ: ניתן ליצור "Export Setup" קבוע עם שמות השכבות המקובלים במשרד שלכם כדי לחסוך זמן בכל ייצוא.–File → Export
EPExport PDF — ייצוא ל-PDF (משופר 2026)
📋 מה זה בכלל? יצירת קובץ PDF מגיליונות השרטוט שלכם. בגרסת 2026 הכלי הפך למהיר וחכם במיוחד, עם תמיכה מובנית בייצוא מרובה מבלי להזדקק למדפסות PDF חיצוניות.
📌 שלב-אחר-שלב: ① File → Export → PDF. ② בחרו את הגיליונות (Sheets) לייצוא. ③ הגדירו את גודל הדף (בדרך כלל <Use Sheet Size> כדי שכל גיליון ייצא בגודל המקורי שלו). ④ בחרו אם לאחד את כולם לקובץ אחד או להפריד.
💡 ב-2026: ניתן להגדיר חוקי שיום אוטומטיים לקבצים המיוצאים לפי פרמטרים של הפרויקט.–File → Export
ENExport NWC — ייצוא לNavisworks
📋 מה זה בכלל? ייצוא המודל לפורמט NWC עבור תוכנת Navisworks. זהו השלב הראשון בביצוע בדיקת התנגשויות (Clash Detection) מורכבת בין כל הדיסציפלינות.
📌 שלב-אחר-שלב: ① File → Export → NWC (אם מותקן ה-Exporter). ② הגדירו ב-Navisworks Settings מה לייצא (למשל: רק אלמנטים נראים). ③ לחצו OK ושמרו את הקובץ.
💡 טיפ: תמיד עדיף לייצא מבט 3D ייעודי שבו מוסתרים אלמנטים מיותרים כמו קווי עזר או צמחייה.–File → Export

Phases — שלבי בנייה ותכנון
תכנון לפי שלבים: קיים, הריסה, שינוי ובנייה חדשה

Phases מאפשרים לך לתאר בנייה קיימת, הריסה ובנייה חדשה באותו מודל. כל אלמנט מקבל שני פרמטרים: Phase Created ו-Phase Demolished. תצוגות מסוננות לפי Phase Filter.

🏚️
Existing — קיים
Phase שנוצר ב-"New Construction" ונהרס ב-"Demolished". שימושי לתיעוד מצב קיים לפני שיפוץ. Phase Filter: "Show Previous + Demo".
💥
Demolition — הריסה
בחר אלמנטים → Properties → Phase Demolished = "Demo Phase". מוצג בסגול ב-Filter "Show Demo". אוטומטית נוצרים קווי הריסה בחתכים.
🏗️
New Construction — חדש
Phase Created = "New Construction". מוצג ב-Filter "Show New Only". בתוכניות הגשה: קירות חדשים שחורים, קיימים אפורים.
🔍
Phase Filters — מסנני שלבים
Manage → Phases → Phase Filters: הגדר מה מוצג לכל Phase Filter. עמודות: New, Existing, Demolished, Temporary. כל שורה = Filter Rule.
1
הגדר Phases
Manage → Phases ← לחץ "New" ← הוסף שלבים: "קיים", "שלב א'", "שלב ב'" ← גרור לסדר הרצוי.
2
שייך אלמנטים
בחר אלמנטים → Properties → Phase Created = "קיים" ← שייך הריסות ל-Phase Demolished = "שלב א'".
3
הגדר תצוגות
פתח View Properties ← Phase = "שלב א'" ← Phase Filter = "Show New + Existing" ← תצוגה מציגה נכון.
4
Graphics Override
Manage → Phases → Graphic Overrides ← הגדר צבעים: Existing = אפור, Demolished = סגול הפסקות, New = שחור.
💡 טיפ: Phased Schedules

צור Schedule עם Phase Filter כדי לספור אלמנטים חדשים בלבד. View → Schedules → Properties → Filter ← Phase Created = "New Construction".

טיפים למקצוענים וסטודנטים
איך לעבוד נכון, מהר ובצורה מקצועית ב-BIM
📁 ניהול קבצים וגיבויים
• שמירה בשם: תמיד שמרו גרסאות (V01, V02) לפני שינויים גדולים.
• Purge Unused: השתמשו בפקודה זו פעם בשבוע כדי לנקות אלמנטים מיותרים ולהקטין את נפח הקובץ.
• Central File: בעבודה במשרד, וודאו שאתם מסנכרנים (Sync) לפחות פעם בשעה.
🏗️ שיטות עבודה (Best Practices)
• אל תשתמשו ב-2D: נסו למדל הכל בתלת-ממד. קווים דו-ממדיים (Detail Lines) הם רק לפרטים קטנים.
• Constraints: תמיד קשרו קירות ורצפות למפלסים (Levels). אם גובה הקומה ישתנה, הכל יתעדכן לבד.
• Naming: תנו שמות ברורים למבטים ופמיליות (למשל: "תוכנית עבודה - קומה 01").
🎓 טיפים לסטודנטים
• Templates: התחילו תמיד מ-Template אדריכלי מסודר. זה יחסוך לכם שעות של הגדרות.
